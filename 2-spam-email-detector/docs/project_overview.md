# Project Overview

This project is a Flask-based spam email detector that uses a machine learning model to classify email text as spam or ham.

## Goals
- Build a beginner-friendly ML web application
- Use Flask and SQLite for the backend
- Train a Naive Bayes classifier on a sample dataset
- Store prediction history in the database

## Architecture
- Flask app entry point: app.py
- Database layer: database/
- Models: models/
- Business logic: services/
- Machine learning: ml/
- Routes and views: routes/ and templates/
